# Extension test fixture

This directory contains the extension fixture used by ZOrca's extension-host
tests and benchmarks. It is not published as a user-facing extension.

ZOrca remains compatible with the Zed extension ecosystem. See
[Zed Extensions](https://zed.dev/extensions) to find extensions or
[Zed's extension documentation](https://zed.dev/docs/extensions/developing-extensions)
to develop one locally.
